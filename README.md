# 01 — Página de Links (estilo Linktree)

> Uma página com seu nome, foto e botões linkando pras suas redes sociais.

---

## Checklist de desenvolvimento

### Estrutura do projeto
- [ ] Criar pasta do projeto com `index.html`, `style.css` e pasta `assets/`
- [ ] Adicionar uma foto sua em `assets/foto.jpg`
- [ ] Subir no GitHub e ativar o GitHub Pages

### HTML semântico
- [ ] Usar `<main>` como container principal
- [ ] Usar `<header>` para nome e foto
- [ ] Usar `<nav>` para a lista de links
- [ ] Cada link dentro de `<a>` com `href` real e `target="_blank"`
- [ ] Foto com `<img>` com `alt` descritivo
- [ ] Sem `<div>` onde existe tag semântica adequada

### CSS
- [ ] Declarar variáveis no `:root` (cor primária, cor de fundo, cor do texto)
- [ ] Foto com `border-radius: 50%` e tamanho fixo
- [ ] Botões com `width` igual e centralizados
- [ ] `hover` nos botões com `transition`
- [ ] Página responsiva: testar no celular (largura ~375px)
- [ ] Sem `<br>` para espaçamento — usar `margin` ou `gap`

### Tipografia e visual
- [ ] Nome em destaque (tamanho e peso maior)
- [ ] Descrição/bio em tamanho menor e cor mais suave
- [ ] Espaçamento consistente entre os botões
- [ ] Contraste adequado entre texto e fundo (testar modo claro e escuro)

### Qualidade
- [ ] Sem erros no console do navegador
- [ ] HTML validado em validator.w3.org
- [ ] README atualizado com print do projeto

---

## Resultado esperado
Página publicada no GitHub Pages com pelo menos 4 links funcionando e design limpo que você não teria vergonha de mostrar pra alguém.
