# 02 — Página de Links (estilo Linktree)

> Uma página com seu nome, foto e botões linkando pras suas redes sociais.

---

## Checklist de desenvolvimento

### Estrutura do projeto
- [x] Criar pasta do projeto com `index.html`, `style.css` e pasta `assets/`
- [x] Adicionar uma foto sua em `assets/foto.jpg`
- [x] Subir no GitHub e ativar o GitHub Pages

### HTML semântico
- [x] Usar `<main>` como container principal
- [x] Usar `<header>` para nome e foto
- [x] Usar `<nav>` para a lista de links
- [x] Cada link dentro de `<a>` com `href` real e `target="_blank"`
- [x] Foto com `<img>` com `alt` descritivo
- [x] Sem `<div>` onde existe tag semântica adequada

### CSS
- [x] Declarar variáveis no `:root` (cor primária, cor de fundo, cor do texto)
- [x] Página responsiva: testar no celular (largura ~375px)
- [x] Sem `<br>` para espaçamento — usar `margin` ou `gap`

### Tipografia e visual
- [x] Nome em destaque (tamanho e peso maior)
- [x] Descrição/bio em tamanho menor e cor mais suave
- [x] Espaçamento consistente entre os botões
- [x] Contraste adequado entre texto e fundo (testar modo claro e escuro)

### Qualidade
- [x] Sem erros no console do navegador
- [x] HTML validado em validator.w3.org

---

## Resultado esperado
Página publicada no GitHub Pages com pelo menos 4 links funcionando e design limpo que você não teria vergonha de mostrar pra alguém.
